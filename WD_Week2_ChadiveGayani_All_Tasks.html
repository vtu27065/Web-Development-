Task 1: Introduction to CSS & Selectors

CSS Syntax and Selectors


CSS means Cascading Style Sheets. CSS is used to control the appearance, colors, fonts, spacing, and layout of HTML webpages.

CSS Syntax Example: selector { property: value; }

Selectors Demonstrated


Element Selector: The body, header, nav, paragraph, and heading elements are styled directly using element selectors.

Class Selector: This paragraph uses the .highlight class selector.

ID Selector: The heading above uses the #main-title ID selector.

Universal Selector: The * selector is used to set box-sizing, margin, and padding.

Box Model Demonstration


This box demonstrates width, height, margin, padding, border, border-radius, box-shadow, and content alignment.

Spacing and Alignment


Content: The text inside the element.

Padding: Space between content and border.

Border: The visible edge around the element.

Margin: Space outside the border.

Clean and Organized Layout


Rounded corners, shadows, consistent spacing, and alignment create a clean webpage layout.
