Task 5: Semantic HTML

Understanding Semantic HTML

Semantic HTML elements clearly describe their meaning and purpose to both browsers and developers.

Examples include header, nav, main, section, article, and footer.

Semantic Elements Used in This Page

  • Header: Contains the introductory information.
  • Nav: Contains navigation links.
  • Main: Contains the main webpage content.
  • Section: Groups related content.
  • Article: Contains independent content.
  • Footer: Contains closing information.

Task 7: Reflection & Learning

My HTML Learning Reflection

During Week 1, I learned the fundamentals of HTML and understood how webpages are structured using HTML5. I learned how to create a proper HTML document using the DOCTYPE declaration, html, head, and body elements. I also learned how to use headings, paragraphs, text formatting, links, images, lists, tables, and forms. The most challenging topic for me was creating the student registration form because it required different input types, radio buttons, checkboxes, dropdown menus, and text areas. I enjoyed learning about hyperlinks, images, and lists because they made the webpage more interactive and organized. I also learned about semantic HTML elements such as header, nav, main, section, article, and footer. These elements help organize webpage content clearly and make the structure easier to understand. HTML will help me in learning web development because it provides the basic structure of every webpage. In the future, I can combine HTML with CSS for designing webpages and JavaScript for adding functionality. Overall, this assignment helped me gain confidence in creating webpages from scratch.
